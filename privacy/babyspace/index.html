개요

ROOT KIM이 제공하는 베이비스페이스(이하 "앱")는 신생아와 영유아를 돌보는 보호자를 위한 육아 기록 서비스입니다. 본 방침은 앱이 처리하는 정보, 처리 목적, 보유 기간과 이용자의 권리를 안내합니다.

모든 기록은 기본적으로 기기에 저장됩니다. 가족 공유 기능을 선택한 경우에만 해당 기록이 Firebase로 전송됩니다.

수집하는 정보와 목적

아기 프로필이름, 생년월일, 성별과 프로필 사진을 프로필 표시와 개월 수 계산에 사용합니다.
육아 기록수유, 기저귀, 수면, 투약 정보를 현황과 통계 제공에 사용합니다.
다이어리보호자가 작성한 내용과 첨부 사진을 육아 일기 기능에 사용합니다.
기기 정보AdMob이 광고 제공과 효과 측정을 위해 광고 ID 등 기기 정보를 처리할 수 있습니다.

저장 위치

프로필과 육아 기록은 기본적으로 기기 내부에 저장됩니다. 가족 공유 기능을 사용하는 경우 수유, 기저귀, 수면과 투약 기록이 Firebase에 저장될 수 있습니다.

앱 접근 권한

  • 카메라: 다이어리와 프로필 사진 촬영에 선택적으로 사용합니다.
  • 사진 및 미디어: 갤러리에서 사진을 선택할 때 사용합니다.
  • 인터넷: 가족 동기화와 광고를 불러올 때 사용합니다.

외부 서비스와 제3자 제공

운영자는 이용자의 개인정보를 원칙적으로 제3자에게 판매하거나 제공하지 않습니다. 가족 공유에 동의한 경우 공유 대상 보호자와 기록이 공유되며, 법령에 따라 제공이 요구되는 경우는 예외로 합니다.

Firebase FirestoreGoogle LLC가 제공하며 선택한 가족 공유 기록의 동기화에 사용합니다.
Google AdMobGoogle LLC가 제공하며 앱의 광고 제공과 효과 측정에 사용합니다.

Google의 데이터 처리 방식은 Google 개인정보처리방침에서 확인할 수 있습니다.

보유 기간과 삭제

  • 기기 내 데이터는 이용자가 직접 삭제하거나 앱을 삭제할 때까지 보관됩니다.
  • Firebase 동기화 데이터는 가족 공유 기능을 해제하거나 앱에서 삭제할 때 서버에서도 삭제됩니다.
  • 단건 기록은 앱의 기록 목록 또는 캘린더에서 삭제할 수 있습니다.
  • 법령에서 별도 보유 기간을 정한 경우에는 해당 기간을 따릅니다.

Firebase 데이터 삭제에 도움이 필요한 경우 아래 문의처로 요청할 수 있습니다.

아동 개인정보와 이용자 권리

앱의 사용자는 아기를 돌보는 만 18세 이상의 부모 또는 보호자입니다. 아기 정보는 보호자가 직접 입력하고 관리하며, 아동이 직접 사용하는 서비스가 아닙니다. 아기 정보는 육아 기록 기능 제공에만 사용하며 광고 맞춤화에 사용하지 않습니다.

이용자는 개인정보의 열람, 정정, 삭제와 처리 정지를 요청할 수 있습니다.
