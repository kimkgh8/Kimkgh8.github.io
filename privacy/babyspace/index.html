1개요

베이비스페이스(이하 “앱”)는 부모와 보호자가 아기의 육아 기록을 관리하고, 선택적으로 가족 구성원과 공유할 수 있도록 제공되는 서비스입니다. 운영자는 「개인정보 보호법」 등 관련 법령에 따라 이용자의 개인정보를 보호하고, 앱에서 처리되는 개인정보의 항목·목적·보유·공유·삭제 방법을 다음과 같이 안내합니다.

아기 프로필과 육아 기록은 기본적으로 기기 내부에 저장됩니다. 다만 광고, 앱 업데이트 설정 확인 및 보안 검증을 위한 기술 정보는 앱 실행 시 외부 서비스에서 처리될 수 있으며, 가족 공유·계정 연결·문의하기는 이용자가 해당 기능을 사용할 때 관련 정보를 서버로 전송합니다.

3기기 내부 저장

  • 구조화된 프로필과 기록은 앱 전용 SQLite 데이터베이스에 저장됩니다.
  • 프로필 사진, 사진 기록 및 다이어리 첨부 파일은 앱 전용 파일 저장소에 보관됩니다.
  • 동의 여부, 선택한 아이, 가족 연결 상태, 타이머 세션 등 일부 설정은 앱 전용 설정 저장소에 보관됩니다.
  • 기기 내부 데이터는 운영자 서버로 자동 백업되지 않지만, 이용자의 운영체제 백업 설정에 따라 Google 또는 Apple의 기기 백업에 포함될 수 있습니다.

기기 내부 데이터는 운영체제의 앱 샌드박스로 다른 앱과 분리됩니다.

4가족 공유 기능

이용자가 가족 공유 기능을 활성화한 경우 다음 정보가 Google Firebase에 업로드되고, 초대로 연결된 가족 구성원이 이를 조회·수정할 수 있습니다.

공유되는 정보

  • 아기 프로필: 내부 식별자, 이름, 생년월일, 성별, 보관 상태
  • 수유·기저귀·수면·투약·성장 기록과 각 기록에 입력한 메모
  • 동기화를 위한 생성·수정·삭제 일시와 수정 사용자 식별자

공유되지 않는 정보

  • 아기 프로필 사진
  • 사진 기록의 이미지와 메모
  • 다이어리 텍스트와 첨부 사진
  • 기기 내부 파일 경로

초대 코드는 충분히 긴 무작위 값으로 생성되며, 서버에는 원문이 아닌 SHA-256 해시가 저장됩니다. 초대는 한 번만 사용할 수 있고 발급 후 24시간이 지나면 만료됩니다. 가족 데이터는 인증된 가족 구성원만 읽을 수 있으며 구성원·초대·영구 삭제 등의 관리 작업은 역할에 따라 제한됩니다.

5계정 연결

가족 공유를 만들거나 참여하려면 Google 또는 Apple 계정을 Firebase Authentication의 기존 사용자 식별자에 연결해야 합니다. 인증 제공자가 전달하는 범위에 따라 고유 계정 식별자, 이메일, 표시 이름 등의 정보가 Firebase Authentication에서 처리될 수 있습니다. 계정 정보는 가족 접근 권한과 방장 권한을 기기 변경 후에도 복구하기 위해 사용됩니다.

6광고 및 추적 관련 정보

앱은 Google AdMob을 통해 배너 광고를 제공합니다. Google Mobile Ads SDK는 광고 제공·측정, 분석 및 부정 사용 방지를 위해 IP 주소, 광고 ID·앱 세트 ID 등 식별자, 앱 및 광고 상호작용, 진단 정보를 자동으로 수집·공유할 수 있습니다. Android 앱은 광고 ID 접근 권한을 사용합니다.

이용자가 입력한 아기 프로필, 육아 기록, 다이어리 및 사진을 앱이 AdMob 광고 타겟팅 정보로 직접 전송하지는 않습니다. 광고 ID는 Android 기기 설정에서 재설정하거나 삭제할 수 있고, 광고 개인화 설정도 기기의 개인정보 보호 또는 광고 설정에서 관리할 수 있습니다.

Google의 광고 데이터 처리에 관한 자세한 내용은 Google Mobile Ads 데이터 공개 안내와 Google 개인정보처리방침을 확인해 주세요.

9보유 및 이용 기간

  • 기기 내부 데이터: 이용자가 앱 안에서 삭제하거나 앱을 삭제할 때까지 보관됩니다. 운영체제 백업본은 해당 백업 제공자의 정책에 따라 더 오래 남을 수 있습니다.
  • 가족 공유 데이터: 가족 연결을 해제해도 서버에서 자동 삭제되지 않습니다. 아이 영구 삭제 또는 가족 전체 영구 삭제를 실행하거나 삭제를 요청할 때까지 보관됩니다.
  • 삭제한 동기화 기록: 다른 가족 기기에 삭제를 전파하기 위해 삭제 일시가 표시된 문서 형태로 남을 수 있으며, 해당 아이 또는 가족을 영구 삭제할 때 제거됩니다.
  • 인증 정보: 연결된 Firebase Authentication 사용자를 삭제할 때까지 보관됩니다.
  • 문의 정보: 문의 처리와 분쟁 대응에 필요한 기간 동안 보관한 후 삭제합니다. 이용자는 언제든 이메일로 조기 삭제를 요청할 수 있습니다.
  • 광고·Firebase 기술 정보: Google이 각 서비스 정책에서 정한 기간 동안 보관합니다.

10정보 삭제와 가족 연결 해제

  • 기록 단건 삭제: 기기에서는 삭제되며, 가족 공유 중인 기록은 다른 기기에 삭제를 전파하기 위한 삭제 표시가 서버에 남을 수 있습니다.
  • 아이 보관: 프로필과 관련 데이터를 유지한 채 활성 선택 목록에서만 제외합니다.
  • 아이 영구 삭제: 권한 확인 후 해당 아이의 Firebase 프로필·공유 기록을 먼저 삭제하고, 성공하면 기기의 프로필·기록·다이어리·사진과 관련 첨부 파일을 삭제합니다.
  • 가족 연결 해제: 해당 사용자의 가족 구성원 관계와 기기의 동기화 연결을 해제하지만, 기기 내부 원본과 가족 서버 데이터는 삭제하지 않습니다. 방장이 나갈 때는 다른 구성원에게 방장 권한이 이전될 수 있습니다.
  • 기기 데이터 삭제: 앱의 설정 메뉴에서 기기 데이터 삭제를 실행하면 기기 DB, 앱 설정과 관리 대상 첨부 파일을 삭제합니다. 가족에 연결되어 있으면 먼저 가족 연결을 해제하며 가족 서버 데이터는 유지됩니다.
  • 가족 전체 영구 삭제: 방장 권한을 확인한 후 가족의 프로필·기록·구성원·초대와 가족 문서를 서버에서 삭제하고 이 기기의 데이터도 삭제합니다.
  • 인증 계정 및 기타 서버 정보: 앱에 자동 계정 삭제 메뉴가 제공되지 않는 경우 아래 이메일로 삭제를 요청할 수 있습니다.
앱을 삭제하는 것만으로 가족 서버 데이터나 Firebase Authentication 사용자가 자동 삭제되지는 않습니다. 서버 데이터 또는 인증 계정 삭제가 필요하면 앱의 영구 삭제 기능을 사용하거나 개인정보 보호책임자에게 요청해 주세요.

11제3자 제공

운영자는 다음 경우를 제외하고 이용자의 개인정보를 제3자에게 제공하지 않습니다.

  • 이용자가 가족 초대를 발급하거나 수락하여 연결된 가족 구성원과 공유하는 데 동의한 경우
  • 이용자가 별도로 동의한 경우
  • 법령에 근거가 있거나 적법한 기관의 요청이 있는 경우

제7조의 외부 서비스 제공자는 기능 제공을 위해 정보를 처리하며, 각 제공자의 약관과 개인정보처리방침이 함께 적용됩니다.

12아동 개인정보

앱의 이용자는 아기를 돌보는 부모 또는 보호자이며, 아동이 직접 가입하여 사용하는 서비스가 아닙니다. 만 14세 미만 아동의 정보는 법정대리인 등 적법한 권한이 있는 보호자가 입력·관리해야 합니다. 보호자는 언제든 아동의 정보를 수정·보관·삭제할 수 있습니다.

이용자가 입력한 아기 프로필과 육아 기록을 앱이 AdMob에 광고 타겟팅 정보로 직접 제공하지 않습니다.

13안전성 확보와 이용자 권리

보호 조치

  • 기기 내부 데이터는 운영체제의 앱 전용 저장 영역에 보관합니다.
  • Firebase 통신은 HTTPS/TLS를 사용하며, 지원 서비스는 저장 데이터 암호화를 적용합니다.
  • Firestore 보안 규칙으로 인증된 가족 구성원만 가족 데이터를 읽고 쓰도록 제한합니다.
  • 초대 코드 원문을 서버에 저장하지 않고, App Check를 통해 비정상 요청 방지를 보조합니다.

이용자와 법정대리인의 권리

  • 개인정보 열람, 정정, 삭제, 처리 정지 요청
  • 가족 공유 중단 및 가족 구성원 관계 해제
  • 인증 계정과 문의 정보 삭제 요청

권리 행사는 앱의 수정·삭제 기능 또는 아래 이메일을 통해 할 수 있으며, 본인 또는 정당한 권한 보유 여부를 확인한 뒤 처리합니다.
