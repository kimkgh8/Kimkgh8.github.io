# 기능: Google Play 개발자 사이트 전환

## 목표
기존 개인 포트폴리오를 제거하고 ROOT KIM의 Google Play 앱, 개인정보처리방침, 고객 지원 정보를 제공하는 정적 사이트로 전환한다. `app-ads.txt`와 Search Console 인증 파일은 그대로 유지한다.

## 관련 파일 위치
- 구현: `index.html`, `apps/`, `privacy/`, `support/`, `assets/css/site.css`
- 테스트: `tests/test_site.py`

## 테스트 목록
- [x] 필수 공개 경로와 파일이 존재한다.
- [x] `app-ads.txt`의 판매자 정보가 변경되지 않는다.
- [x] 공개 페이지에서 개인 포트폴리오 정보가 노출되지 않는다.
- [x] 두 Google Play 앱의 정확한 패키지와 스토어 링크를 제공한다.
- [x] 앱별 개인정보처리방침에 데이터 처리, 보유, 삭제, 문의 정보가 있다.
- [x] 모든 페이지가 한국어 문서 구조와 접근성 기본 요소를 갖는다.
- [x] 다크 모드, 모션 감소, 모바일 레이아웃이 CSS에 정의된다.
- [x] 기존 포트폴리오 경로와 콘텐츠 파일이 배포 대상에서 제거된다.
- [x] 외부 링크가 안전한 속성을 사용한다.
- [x] 공개 문구에 금지된 대시 문자가 없다.

## 완료 기준
- 모든 Python 정적 검증 테스트 통과
- 정적 서버에서 주요 URL 응답 확인
- HTML 검증 및 링크 검증 완료
- 모바일과 데스크톱 렌더링 시각 검수 완료
- `app-ads.txt`가 `text/plain`으로 제공될 구조 유지
